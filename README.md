# Briv AI - Backend

This is the backend server for the Briv AI full-stack application. It is built using **Flask** and provides authentication and API support for the frontend.

## 📦 Features

- User registration and login
- CORS support for frontend interaction
- Logs for request tracking
- Modular Flask structure

## 🛠 Requirements

- Python 3.8+
- Flask
- Gunicorn (for production)
- Other packages listed in `requirements.txt`
